# input-assets (local only)

Owner-supplied originals live here and are **git-ignored**: the drawings are not
approved for publication. Expected layout:

```
input-assets/
  brand/        official logo files
  exterior/     exterior renders or photos
  interior/     interior renders or photos
  floorplans/   plans and top-down views
  programs/     program photography (none supplied yet)
  references/   source PDFs and inspiration
```

Each file is listed with its checksum, dimensions, category, rights status and
proposed use in `docs/assets/asset-manifest.json`; the visual reading is in
`docs/assets/visual-analysis.md`. Keep originals unchanged.
