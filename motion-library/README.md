# 🎬 مكتبة الموشن جرافيك والمونتاج

مرجع موحّد لكل ما يخص مقاطع الموشن جرافيك والانتقالات والمونتاج.
كل برومت أو مهارة جاهزة تُحفظ هنا مصنّفة، حتى تكتمل المكتبة ونبدأ مونتاج الفيديوهات.

---

## 📂 هيكل المكتبة

| المجلد | المحتوى |
|---|---|
| `prompts/transitions/` | الانتقالات بين المشاهد (Wipe, Zoom, Glitch, Whip-pan, Morph…) |
| `prompts/text-animation/` | تحريك النصوص والعناوين (Kinetic typography, Typewriter…) |
| `prompts/intros-outros/` | المقدمات والخواتيم |
| `prompts/lower-thirds/` | الأشرطة السفلية (الاسم/المسمى/المعلومة) |
| `prompts/logo-reveals/` | ظهور الشعار |
| `prompts/backgrounds-fx/` | الخلفيات والمؤثرات (Light leaks, particles, gradients, grain…) |
| `prompts/captions/` | الترجمة والكابشن المتحرك |
| `prompts/editing-styles/` | أساليب المونتاج الكاملة (YouTube, Reels, Ads, Documentary…) |
| `prompts/ai-video-generation/` | برومتات توليد الفيديو بالذكاء الاصطناعي |
| `prompts/brand-campaigns/` | إعلانات وحملات كاملة لعلاماتنا (RESHAPE…) |
| `prompts/general/` | أي شيء لا يندرج تحت ما سبق |
| `skills/` | المهارات المحفوظة + فهرس الأدوات المتاحة في البيئة |
| `brands/` | ملفات الهوية لكل علامة (شعار، ألوان، خطوط، صوت، روابط) — تبدأ بـ `brands/reshape/BRAND.md` |
| `_templates/` | قالب حفظ البرومت |

## 📑 الفهارس

- **[INDEX.md](INDEX.md)** — كتالوج كل البرومتات المحفوظة (رقم، اسم، تصنيف، أداة).
- **[skills/TOOLKIT.md](skills/TOOLKIT.md)** — المهارات والأدوات الجاهزة في هذه البيئة للمونتاج والموشن.
- **[CLAUDE.md](CLAUDE.md)** — قواعد الحفظ والتنظيم (يقرأها Claude تلقائيًا).

## 🔄 طريقة العمل

1. ترسل البرومت/المهارة كما هي.
2. يُحفظ النص **حرفيًا** في ملف داخل التصنيف المناسب باستخدام القالب.
3. يُضاف سطر في `INDEX.md`.
4. يُعمل commit و push حتى لا يضيع شيء (البيئة مؤقتة).
5. عند بدء المونتاج: نرجع للفهرس ونختار البرومتات المناسبة لكل فيديو.
