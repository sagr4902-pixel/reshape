# RESHAPE — النوم مو رفاهية… النوم صحة
Premium Saudi health-awareness motion-graphics film (9:16, 1080×1920, 30 fps, 48.5 s).

## Deliverables (`out/`)
| File | What |
|---|---|
| `RESHAPE_Sleep_Health_Awareness.mp4` | Final film, H.264 + AAC, loudness −14 LUFS / −1 dBTP |
| `RESHAPE_Sleep_Health_VO.wav` | Voice-over only, on the film timeline, 48 kHz / 24-bit mono |
| `RESHAPE_Sleep_Health.srt` | Arabic subtitles, timed from the measured narration |
| `RESHAPE_Sleep_Health_Cover.png` | Vertical cover built from the same design system |
| `RESHAPE_Sleep_Research.md` | Study citations, limitations and the claim-by-claim audit |
| `RESHAPE_Sleep_Instagram_Caption.md` | Saudi Arabic caption + references |

## Project layout
- `src/` — Remotion composition. `timeline.ts` is the master clock (scene ranges + where each
  VO segment sits). `captions.ts` is generated by `audio/make_captions.py`.
- `src/scenes/` — one file per scene (Hook, Brain, Immune, HeartScene, Regular, Advice, Finale).
- `src/components/` — Background, Scene (enter/exit), Text (kinetic headline, eyebrow, study chip),
  Subtitles, Icons (brain network, heart, shield, calendar/advice icons).
- `src/brand.ts` — colours/fonts copied from the production site's `:root` tokens.
- `public/brand/` — official logo PNGs extracted from the site. `public/fonts/` — Zain,
  IBM Plex Sans Arabic, Barlow Semi Condensed (Google Fonts, OFL).
- `audio/` — `vo-takes/` (ElevenLabs takes + aligned words), `sfx/` (ElevenLabs sound effects),
  `make_music.py` (procedural, royalty-free cinematic bed), `build_mix.py` (cuts the VO to the
  timeline, places SFX, ducks music), `make_captions.py` (SRT + on-screen cues), `timeline.json`.

## Rebuild
```bash
npm install
python3 audio/make_music.py && python3 audio/build_mix.py && python3 audio/make_captions.py
ffmpeg -i public/audio/mix.wav -af loudnorm=I=-14:TP=-1:LRA=9 -c:a pcm_s24le public/audio/mix_norm.wav && mv public/audio/mix_norm.wav public/audio/mix.wav
npm run render      # out/RESHAPE_Sleep_Health_Awareness.mp4
npm run still       # out/RESHAPE_Sleep_Health_Cover.png
npm run studio      # live preview
```
