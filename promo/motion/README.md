# RESHAPE — فيلم موشن (23 ثانية، 1080×1920، 60 فريم)

`reshape-motion.mp4` هو الفيلم النهائي: صوت ElevenLabs (عبدالرحمن، نجدي حماسي) + مؤثرات صوتية، بلا ملف صوتي بالخلفية، ومعايرة -14 LUFS.

| ملف | شنو فيه |
|---|---|
| `script.json` | السكربت المنطوق (8 أسطر) |
| `facts.md` | كل رقم واسم على الشاشة ومن وين أخذناه من `index.html` |
| `project.json` · `theme.json` | الألوان والخطوط والمشاهد والانتقالات |
| `src/` | المشاهد (`_lib.js` مشترك، `tools/build.sh` يركّبها في `scenes/`) |
| `sfx.json` | المؤثرات الصوتية ومواقعها |
| `words.json` | توقيت كل كلمة (تقريبي من وقفات الصوت) |
| `assets/` · `fonts/` | الشعارات من الموقع، وخطوط Zain وBarlow (رخصة OFL) |

مبني بمحرّك سكل «شرح بالموشن» (`video-ad-editor/motion`).
