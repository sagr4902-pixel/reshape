# RESHAPE — 35 s in-club group training commercial (Remotion)

Vertical 1080×1920, 30 fps, H.264 + AAC 48 kHz. Promotes **in-club group classes only**.
Final files and the QA reports are in `../deliverables/`.

Two versions live in this project:

| Composition | What it is | Output |
| --- | --- | --- |
| `ReshapeMotionGraphics` | **Current version.** 100 % 2D/2.5D motion graphics, Saudi VO with the corrected brand pronunciation (ree-SHAYP), soft SFX only, **no music** | `RESHAPE_Premium_Motion_Graphics_35s.mp4` |
| `ReshapeCommercial` | Original v1 (CGI equipment + original score), kept unchanged | `RESHAPE_Club_Commercial_35s.mp4` |

## reshape-online.com films

| Composition | What it is |
| --- | --- |
| `ReshapeOneDay169` / `ReshapeOneDay916` | **"One Day" (v2), ~57 s.** One actor (always from behind) through one day, shot as if by one camera: chained Kling clips, his phone showing the real app (Account page, today's workout, session video, nutrition, progress + medal), and at dusk he types reshape-online.com while the voice says it; the site then fills the frame before the end card. SFX only, no music. |
| `ReshapeCinematic169` / `ReshapeCinematic916` | The first 45 s cinematic cut (v1), kept unchanged. |

How "One Day" is built (job IDs for every generated image and clip are in `public/ad/MEDIA.json` → `v2_one_day`):

1. **Continuity.** A back-view character reference feeds every keyframe; each Kling 3.0 clip gets the previous shot's keyframe as `start_image` and the next as `end_image`, so the dawn sequence (`c02`–`c06`) cuts on identical frames and reads as one take, ending in a push into his shirt that opens onto the desert.
2. **Phone screens.** Keyframes carry a flat chroma-green screen. `scripts/build_screen_tracks.py` assembles each shot's screen timeline from Playwright captures of the real site (mocked backend, synthetic trainee), and `scripts/phone_comp.py` tracks the green quad per frame, warps the capture in with a homography, keeps fingers in front through a soft key and removes the green spill from the hands. `--quads` exports the tracked corners; `scripts/write_screen_quads.py` turns the dusk shot's last corners into `src/oneday/screenQuads.ts` so the website stage starts exactly on the hand-held phone.
3. **Edit.** `src/oneday/timeline.ts` (shots, rates, transitions, supers) and `src/oneday/OneDay.tsx` (bloom, whips, "8 weeks later" card, typed URL, website stage, end card). Clips live in `public/ad/v2/{h,v}/cNN.mp4` (git-ignored; re-download by job ID).
4. **Sound.** `python3 scripts/build_oneday_audio.py` → `public/ad/oneday_mix.wav` (−14 LUFS, −1 dBTP). The voice is a premium Saudi white dialect, not Fusha (`public/ad/vo/od*.wav`, trimmed to speech; `od11` speaks the address; the brand vowel was checked with `scripts/vowel_probe.py`); new foley and beds are in `public/ad/sfx2`.
   Screens follow the light: morning shots show the app in dark mode, evening shots (kitchen, sunset, dusk website) in light mode.
5. **Final QA.** `python3 scripts/qa_oneday.py <render.mp4> <models_dir>`: specs, loudness, brand vowel inside the mix, face scan.
6. **Clip QA.** `python3 scripts/qa_faces.py <clip> <models_dir> <out_dir>` on every clip (no face, no eyes; hits are reviewed by eye).

## Motion-graphics version

```
npm run studio          # pick ReshapeMotionGraphics (or Motion-hook / -brand / -group / -transformation / -cta, MotionLab)
npm run preview:motion  # half-res check render → out/preview_motion.mp4
npm run render:motion   # final → out/RESHAPE_Premium_Motion_Graphics_35s.mp4 (~25 min on 4 cores)
python3 scripts/qa_motion.py out/RESHAPE_Premium_Motion_Graphics_35s.mp4   # specs, loudness, no-music + pronunciation QA
```

| Path | What it is |
| --- | --- |
| `src/motion/MotionCommercial.tsx` | Master composition: stage, five scene sequences, slanted brand wipes, VO + SFX stems (no music) |
| `src/motion/scenes/M1Hook … M5Cta` | One file per scene; every animation is keyed to the spoken word (`mword`) |
| `src/motion/Athlete.tsx` | Athletic silhouette rig: forward kinematics → tapered solid shapes; poses and exercise cycles (squat, swing, deadlift, run, jump squat, climb) |
| `src/motion/kit.tsx` | Motion building blocks: slant bars, drawn paths, rings, chevrons, perspective floor, RTL progress bar, layered headline, wipe |
| `src/motion/design.ts` | Tokens: #FF5420 / #17181A / #FFFFFF, the brand slant (−14°), safe area |
| `src/motion/timeline.json` | Scene cuts + every VO word time, generated by `scripts/build_motion_audio.py` |
| `public/audio/motion/` | `vo.wav` + `sfx.wav` (their sum is the −14 LUFS mix) |
| `audio-src/vo_line2_brand_ipa_A.mp3`, `vo_line5_cta_ipa_A.mp3` | Regenerated takes with the corrected «RESHAPE» |
| `scripts/vowel_probe.py`, `scripts/brand_spectrogram.py`, `qa/` | Acoustic pronunciation check (formants of the «SHAYP» vowel) and evidence |

Rebuild the soundtrack with `npm run audio:motion`, then the SRT and VO WAV with
`python3 scripts/make_deliverables.py --motion`. To change copy timing, edit the word times in
`build_motion_audio.py`; every scene follows `timeline.json` automatically.

## Original version (v1)

```
npm install
npm run studio        # live preview / scrub
npm run preview       # half-res check render → out/preview.mp4
npm run render        # final → out/RESHAPE_Club_Commercial_35s.mp4 (~35 min on 4 CPU cores)
```

The render uses the container's Chromium headless shell and SwiftShader WebGL
(`remotion.config.ts`); on a normal machine you can delete the `setBrowserExecutable` line.

| `public/brand/` | Logo source PNG from the production site + traced SVGs |
| `audio-src/` | The approved ElevenLabs voice-over takes the VO stem is cut from |

## Swapping in real club footage

Every CGI shot sits inside a `<FootageSlot>`. Put approved, RESHAPE-owned clips in
`public/footage/` and name them in `src/lib/footage.ts`; the shot is replaced, while timing,
typography and audio stay as they are. Never use third-party social-media video.

## Rebuilding audio

```
pip install numpy scipy soundfile pyloudnorm
python3 scripts/build_audio.py        # VO edit + original score + SFX + timeline.json
python3 scripts/make_deliverables.py  # SRT + VO WAV in out/
```

The score and SFX are synthesised from scratch in `build_audio.py` (no samples, no licensed
tracks), so they are safe for paid social. To use a licensed track instead, replace
`public/audio/music.wav` (35.0 s, 48 kHz).

## Logo

`scripts/vectorize_logo.py` traces the logo PNG found in the production site into
`src/components/logoPaths.ts`. The source is only 420 px wide, so if RESHAPE has a master
vector logo (SVG/AI/PDF), drop its paths into `logoPaths.ts` for a perfectly crisp end card.
