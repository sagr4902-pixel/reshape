# RESHAPE Online — «لوحة تقدّمك» (v1)

ريل عمودي 26.6 ث لـ **ريشيب أونلاين**، **أنيميشن بالكامل وبدون موسيقى** — تعليق صوتي بصوت محمد الصقر (لهجة بيضاء، القاف تُنطق عادي /q/ ومتحقَّق منها بالقياس) + أصوات واجهة متزامنة مع كل حدث (مبني على المرجع 015 في المكتبة).

لقطة واحدة متصلة: الكاميرا تنزلق على لوحة ودجتس مائلة بهوية ريشيب، وكل ودجت يتعبّى لحظة ما توصله:

| الودجت | الصوت |
|---|---|
| عنوان «لوحة تقدّمك» + المربعات تتجمع | «هذي لوحة تقدّمك.» |
| أيام تمرينك (١٢ تمرين هالشهر) | «كل تمرين… ينحسب.» |
| العقلة ٢ ← ٥ ← ٨ (الأرقام على «ثنتين» و«لثمان») | «ع البار… من ثنتين لثمان.» |
| ساعة التمرين ٥:٣٠ م | — (أصوات فقط) |
| وقفة اليد ٠ ← ١٠٠٪، «✓ أتقنتها» على «صارت» | «ووقفة اليد… صارت لك.» |
| متابعتك الجاية: الأحد ٥:٣٠ م · مكالمة فيديو · مع مدربك أونلاين | «ومدربك معك أونلاين… خطوة بخطوة.» |
| ١٢ يوم ما وقفت | — (أصوات فقط) |
| مسارك: البداية ← أول عقلة ← أول وقفة يد ← أول ليفر | «من أول حركة… لأقوى نسخة منك.» |

| ختام بنفس هوية اللوحة: مربعات تنزل فوق اللوحة المموّهة — الشعار الرسمي ← «ريشيب أونلاين» ← «ابدأ اليوم» ← reshape-online.com | «ريشيب أونلاين… ابدأ اليوم!» |
