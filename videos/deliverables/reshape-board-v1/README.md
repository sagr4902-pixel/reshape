# RESHAPE — «لوحة تقدّمك» (v1)

ريل عمودي 20.4 ث، **أنيميشن بالكامل وبدون موسيقى ولا تعليق صوتي** — الإيقاع كله من أصوات واجهة متزامنة مع كل حدث (مبني على تحليل المرجع 015 في المكتبة).

لقطة واحدة متصلة: الكاميرا تنزلق على لوحة ودجتس مائلة بهوية ريشيب، وكل ودجت يتعبّى لحظة ما توصله الكاميرا:
أيام التمرين في الشهر (١٢ حصة) ← العقلة ٢ ← ٥ ← ٨ ← ساعة الحصة ٥:٣٠ م ← وقفة اليد ٠ ← ١٠٠٪ «أتقنتها» ← حصتك الجاية مع مدربك ← ١٢ يوم ما وقفت ← مسارك: البداية ← أول عقلة ← أول وقفة يد ← أول ليفر ← رجوع للوحة كاملة «تقدّمك… ينشاف.» ← الشعار الرسمي + «ابدأ اليوم».
