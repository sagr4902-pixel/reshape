# RESHAPE — «هذا إنت؟» (v3 · ريل حماسي قصير)

نسخة ثالثة أقصر وأحمس: هوك «فيديو منزلي» لمحاولة وقفة يد فاشلة ← تجميد + خدش أسطوانة + دائرة حمراء + «هذا إنت؟» ← ترجيع بالمؤشر ← ضغطة ▶ تتحوّل لكرة ← انفجار «أول عقلة! / أول وقفة يد! / أول ليفر!» ← ومضات كلمات ← الأطفال «أول خطوة… بثقة!» مع هاي فايف ← فسيفساء + كبسولات زجاجية «في ريشيب… تدريب حضوري» ← شريط تقدّم يمتلئ على «والتقدّم… ينشاف!» ويتفكّك لمسارات تكوّن الشعار ← «ابدأ اليوم». صوت محمد الصقر (لهجة بيضاء، والقاف تُنطق **عادي /q/** في «عقلة، وقفة، بثقة، التَّقَدُّم» — متحقَّق منها بالقياس)، **بدون موسيقى** — الإيقاع من المؤثرات.

| الملف | الوصف |
|---|---|
| `RESHAPE_hype_v3_1080x1920_30fps.mp4` | الماستر — 1080×1920، 30fps، H.264 (CRF 16) + AAC 320k، الصوت −14 LUFS / −1.5 dBTP (ما ينرفع على GitHub؛ يُعاد بـ `bash scripts/render_hype.sh`) |
| `RESHAPE_hype_v3_web.mp4` | نسخة خفيفة للمشاركة (نفس الدقة) |
| `RESHAPE_hype_v3_cover_1080x1920.png` | غلاف الريل (لقطة الهوك) |
| `instagram_caption.md` | الكابشن مع دعوة «اكتب: ابدأ» |
| `*.wav` | المكساج والستيمات (تُولّد بـ `python3 scripts/cues3_build.py`) |

**المهارات والبرومتات المستخدمة:** انتقالات `@remotion/transitions` (wipe / flip / slide / clock-wipe) · تسرّب ضوء، وميض، انحراف لوني، أشعة، خطوط مسح، زجاج سائل (CSS/SVG لأن WebGL ما يشتغل هنا) · Motion blur · ElevenLabs (الصوت المستنسخ + مؤثرات جديدة: خدش، ترجيع، ضربة، كرة) · برومت 001 (المؤشر يقود التغيير + تحوّل زر ▶) · 005 (الكرة تقود الانتقال) · 006 (ومضات الكلمات + الكبسولات الزجاجية) · 008 (المسار البرتقالي والشعار الرسمي) · 009 (الفسيفساء والنص بالظل المزاح) — موثّق كقالب في المكتبة `010`.

**المصدر:** `videos/src/films/hype/` (المشاهد `scenes.tsx`، المؤثرات `fx.tsx`، التوقيت `timeline.ts`) — السكربت `scripts/vo3_script.json`، اختيار اللقطات `scripts/vo3_select.py`، فحص نطق القاف `scripts/vo3_verify.py`، المؤثرات الصوتية `scripts/cues3_build.py`.
