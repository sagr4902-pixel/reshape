# RESHAPE — «اختبار سريع: تمرين؟ ولّا تقدُّم؟» (v2)

نسخة ثانية مبنية بنفس أسلوب الفيديو المرجعي (اختبار تفاعلي، تايبوقرافي متحرك على ورق، لوحات ملوّنة، شخصية مربعة بحبل)، بألوان RESHAPE، وصوت محمد الصقر باللهجة البيضاء. بدون موسيقى.

| الملف | الوصف |
|---|---|
| `RESHAPE_quiz_v2_1080x1920_30fps.mp4` | الماستر — 1080×1920، 30fps، H.264 + AAC، الصوت −14 LUFS (كبير الحجم فما ينرفع على GitHub) |
| `RESHAPE_quiz_v2_web.mp4` | نسخة خفيفة للمشاركة |
| `RESHAPE_quiz_v2_cover_1080x1920.png` | غلاف الريل |
| `instagram_caption.md` | الكابشن مع دعوة «اكتب: ابدأ» |
| `*.wav` | المكساج والستيمات (تُولّد بـ `python3 scripts/cues2_build.py`) |

**المصدر:** `videos/src/films/quiz/` — السكربت في `scripts/vo2_script.json`، والتوقيت في `src/films/quiz/timeline.ts`. إعادة التصدير: `bash scripts/render_quiz.sh`.
